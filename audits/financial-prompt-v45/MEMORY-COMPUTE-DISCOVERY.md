## 4. Native arithmetic signatures and differences from v4.4 analytics_compute

It defaults to close/price/value or the first suitable field, refuses multi-symbol ambiguity but not every metric/period ambiguity. 5. Native calculate does not enforce same entity/date across independent input refs; output does include selected time if extracted. Native compute ratio also lacks strict date alignment. Bench derived correctness must check semantic alignment independently.
6. `/src/core/tools/calculate/units.ts:20–72`: Vietnamese magnitudes and VND base aliases supported. Unknown text gets a new dimension; `VNDbn` is not normalized to tỷ đồng by this parser (static result of term matching), unlike v44 analytics aliases.
